# Driver Inventory Reporter - DGX Spark

## Overview

Comprehensive driver enumeration tool for DGX Spark devices that collects device-to-driver bindings across PCI, NIC interfaces, storage devices, USB devices, and GPUs. Builds a deterministic driver manifest showing which kernel modules are used by which devices, enriched with modinfo metadata.

## Requirement Statement

**Driver enumeration (GPU/NIC/storage/USB/etc.) - Sources: OS inventory + driver manifest**

Provides complete visibility into kernel driver bindings and loaded modules to support:
- Driver troubleshooting and conflict resolution
- Security compliance (driver signing verification)
- Update planning (driver version tracking)
- Hardware compatibility validation
- Asset inventory completeness

---

## Purpose and Scope

### Why Driver Inventory Matters

- **Troubleshooting**: Identify driver issues, conflicts, and missing bindings
- **Security**: Verify driver signatures and track unsigned/out-of-tree modules
- **Compliance**: Document driver versions for regulatory requirements
- **Updates**: Plan driver updates with complete dependency visibility
- **Support**: Provide complete driver manifest during support cases

### Components Covered

| Category | Information | Sources |
|----------|-------------|---------|
| **PCI Devices** | Device-driver bindings, kernel modules | `lspci -D -nnk` |
| **NIC Interfaces** | Interface drivers, versions, firmware | `ethtool -i`, sysfs, PCI correlation |
| **Storage** | Block device drivers | `lsblk`, sysfs driver symlinks |
| **GPU** | GPU drivers, versions | `nvidia-smi`, PCI bindings |
| **USB** | USB device drivers | `lsusb -t`, sysfs |
| **Driver Manifest** | Module metadata, device usage tracking | `lsmod`, `modinfo` |

## Manual Verification Commands

### PCI Device-Driver Bindings

```bash
# Full PCI device list with drivers
lspci -D -nnk

# Filter to key device classes
lspci -D -nnk | grep -A 3 -E "Ethernet|Network|VGA|3D|NVMe|USB"

# Check specific device
lspci -D -nnk -s 0005:01:00.0
```

### NIC Interface Drivers

```bash
# List interfaces
ip -br link

# Check driver for specific interface
ethtool -i enp5s0
ethtool -i wlan0

# Check all interfaces
for iface in $(ip -br link | awk '{print $1}' | grep -v '^lo$'); do
  echo "=== $iface ==="
  ethtool -i $iface 2>/dev/null || echo "ethtool not supported"
done
```

### Storage Drivers

```bash
# List block devices
lsblk -o NAME,TYPE,SIZE,MODEL,TRAN

# Check driver for specific device
ls -l /sys/block/nvme0n1/device/driver
readlink /sys/block/nvme0n1/device/driver
```

### GPU Drivers

```bash
# GPU info with driver version
nvidia-smi --query-gpu=index,name,driver_version,pci.bus_id --format=csv

# Check GPU kernel driver from PCI
lspci -D -nnk | grep -A 3 "3D controller\|VGA"
```

### USB Drivers

```bash
# USB device tree with drivers
lsusb -t

# USB device list
lsusb

# Check USB driver from sysfs
ls -l /sys/bus/usb/devices/*/driver
```

### Loaded Modules

```bash
# List all loaded modules
lsmod

# Check specific module
lsmod | grep mlx5_core

# Get module information
modinfo mlx5_core
modinfo nvidia
modinfo nvme
```

## Understanding the Driver Manifest

The driver manifest is the core output of this tool. It answers the question: **"Which devices use which drivers?"**

### How the Manifest is Built

1. **Collect referenced modules** from:
   - PCI devices (`kernel_driver_in_use` + `kernel_modules`)
   - NIC interfaces (`driver` from ethtool)
   - Storage devices (`driver` from sysfs)
   - USB devices (`driver` from lsusb -t)
   - Known NVIDIA modules (if loaded)

2. **Enrich with modinfo** for each module:
   - Version, license, description
   - Driver signature information (signer, sig_key)
   - Kernel version compatibility (vermagic)
   - Dependencies

3. **Track device usage** for each module:
   - Which PCI devices use it
   - Which NICs use it
   - Which storage devices use it
   - Which USB devices use it

4. **Sort for determinism**:
   - Modules sorted alphabetically
   - Device lists within `used_by` sorted

### Use Cases

**1. Driver Troubleshooting**
```bash
# Find which devices use a specific driver
jq '.drivers_manifest[] | select(.module == "mlx5_core")' driver_inventory.json

# Check if driver is loaded
jq '.drivers_manifest[] | select(.module == "nvidia") | .loaded' driver_inventory.json

# Find drivers with no device bindings (may indicate issues)
jq '.drivers_manifest[] | select(.used_by.pci_devices == [] and .used_by.net_ifaces == [])' driver_inventory.json
```

**2. Driver Signature Verification**
```bash
# List unsigned drivers
jq '.drivers_manifest[] | select(.modinfo.signer == null) | .module' driver_inventory.json

# Check driver signing authority
jq '.drivers_manifest[].modinfo.signer' driver_inventory.json | sort -u
```

**3. Driver Version Tracking**
```bash
# Get all driver versions
jq '.drivers_manifest[] | {module: .module, version: .modinfo.version}' driver_inventory.json

# Check NVIDIA driver version
jq '.drivers_manifest[] | select(.module == "nvidia") | .modinfo.version' driver_inventory.json
```

**4. Dependency Analysis**
```bash
# Find drivers with dependencies
jq '.drivers_manifest[] | select(.modinfo.depends != null and .modinfo.depends != "") | {module: .module, depends: .modinfo.depends}' driver_inventory.json
```

## Troubleshooting

### modinfo Returns No Data for Some Modules

**Symptom:**
```json
{
  "module": "pcieport",
  "modinfo": null,
  "loaded": null
}
```

**Cause**: Built-in kernel modules don't have separate .ko files.

**Resolution**: Expected behavior. Built-in modules are included in manifest but modinfo may be null.

### Virtual Interfaces Shown with is_virtual: true

**Symptom:**
```json
{
  "ifname": "docker0",
  "is_virtual": true,
  "driver": null
}
```

**Cause**: docker0, veth*, br-* are virtual interfaces.

**Resolution**: Expected behavior. Virtual interfaces are included but typically have null driver (they don't use loadable modules).

### USB Driver Shows [none]

**Symptom**: In lsusb -t output, some devices show `Driver=[none]`.

**Cause**: Device has no driver bound, or uses a userspace driver.

**Resolution**: Expected behavior. Tool captures this as `driver: null` in the manifest.

### lspci -nnk Shows No Driver for Some Devices

**Symptom:**
```json
{
  "pci_addr": "0000:00:00.0",
  "kernel_driver_in_use": null,
  "kernel_modules": []
}
```

**Cause**: Device has no driver bound.

**Resolution**: Expected behavior. These devices are included in the manifest but may not have driver bindings.

### Driver Manifest is Large

**Symptom**: Output JSON is several megabytes.

**Cause**: Many referenced modules with full modinfo.

**Resolution**: Use `--no_modinfo` for faster collection with smaller output:
```bash
python3 src/driver_inventory_reporter.py --no_modinfo --output /tmp/drivers_minimal.json
```

## Security and Compliance

### Driver Signature Verification

The tool captures driver signature information from modinfo:
- **signer**: Signing authority
- **sig_key**: Signature key fingerprint
- **sig_hashalgo**: Hash algorithm used

Use this to verify all drivers are properly signed:

```bash
# Find unsigned drivers
jq '.drivers_manifest[] | select(.modinfo.signer == null) | .module' driver_inventory.json

# Verify signing authority
jq '.drivers_manifest[] | {module: .module, signer: .modinfo.signer}' driver_inventory.json
```

### Compliance Use Cases

- **Secure Boot**: Verify all loaded drivers are signed
- **Out-of-tree Modules**: Identify non-distribution modules
- **Driver Updates**: Track driver versions for patch management
- **Audit Trail**: Maintain historical driver inventory for compliance

## Integration with Management Systems

### CMDB Integration

```python
import json

# Load driver inventory
with open("driver_inventory.json") as f:
    inv = json.load(f)

# Extract key driver versions for CMDB
driver_versions = {
    "nvidia": next((m["modinfo"]["version"] for m in inv["drivers_manifest"] if m["module"] == "nvidia"), None),
    "mlx5_core": next((m["modinfo"]["version"] for m in inv["drivers_manifest"] if m["module"] == "mlx5_core"), None),
    "nvme": next((m["modinfo"]["version"] for m in inv["drivers_manifest"] if m["module"] == "nvme"), None)
}

print(f"NVIDIA driver: {driver_versions['nvidia']}")
print(f"Mellanox driver: {driver_versions['mlx5_core']}")
print(f"NVMe driver: {driver_versions['nvme']}")
```

| `pci[].kernel_driver_in_use` | PCIeDevice | Oem/KernelDriver |
